# FounderOS

아이디어만 입력하면 **AI 전문가 팀이 실시간으로 토론하여 설계**를 만들고,
구축 요청을 누르면 **실행 계획과 프로젝트 파일**까지 자동으로 생성하는 플랫폼입니다.

## 이런 순서로 진행됩니다

1. **아이디어 입력**
   - 서비스 이름, 해결할 문제, 대상 고객, 제약 사항 등을 자유롭게 적습니다.
   - 템플릿도 제공되니, 빈 칸이 부담스러우면 템플릿부터 시작해보세요.
2. **AI 전문가 팀 토론**
   - 시장 분석가, 제품 전략가, 기술 설계자 등 역할별 전문가가 의견을 제시합니다.
   - 서로의 의견을 검토하고 토론한 뒤, 최종 합의안을 도출합니다.
3. **최종 합의 & 설계도 생성**
   - 모든 의견을 종합해 시스템 구조, 핵심 흐름, 리스크 관리 방안을 정리합니다.
4. **구축 실행**
   - 합의된 설계를 기반으로 실행 계획서와 프로젝트 파일을 자동 생성합니다.
   - 생성된 파일은 `generated/<설계ID>` 폴더에 저장됩니다.
5. **AI 팀과 대화**
   - 구축 완료 후, 각 전문가에게 질문하거나 추가 작업을 지시할 수 있습니다.

## 기술 스택
- TypeScript / Node.js / Express
- OpenAI SDK (`openai`)

## 실행 방법

```bash
npm install
cp .env.example .env
# .env 파일에 OPENAI_API_KEY 설정 (필수)
npm run dev
```

브라우저에서 `http://localhost:3000` 에 접속합니다.

## 환경 변수
| 변수 | 필수 | 기본값 | 설명 |
|------|------|--------|------|
| `OPENAI_API_KEY` | ✅ | — | OpenAI API 키 |
| `OPENAI_MODEL` | — | `gpt-4o-mini` | 사용할 AI 모델 |
| `PORT` | — | `3000` | 서버 포트 |

## API 엔드포인트
| 메서드 | 경로 | 설명 |
|--------|------|------|
| `GET` | `/api/health` | 시스템 연결 상태 확인 |
| `POST` | `/api/design` | AI 설계 실행 (실시간 스트리밍) |
| `POST` | `/api/build/:designId` | 설계 기반 구축 실행 |
| `GET` | `/api/design/:designId` | 설계 결과 조회 |
| `GET` | `/api/build/:designId` | 구축 결과 조회 |
| `GET` | `/api/workshop/:designId` | 가상 작업실 상태 조회 |
| `POST` | `/api/workshop/:designId/cycle` | 멀티 에이전트 자동 작업 사이클 실행 |
| `POST` | `/api/workshop/:designId/approval/:approvalId` | 중요 사안 사용자 승인/반려 처리 |
| `POST` | `/api/chat/:designId` | AI 전문가와 대화 |

## 주요 개선 사항
- **직관적 UI**: 다크 글래스모피즘 테마, 단계별 진행 표시, 에이전트 아바타 시각화
- **쉬운 안내**: 처음 사용하는 분을 위한 3단계 가이드와 용어 설명 제공
- **아이디어 템플릿**: 크리에이터/소상공인/자기계발 시나리오를 즉시 로드
- **한글 역할명**: AI 전문가 역할을 한글로 표시 (시장 분석가, 제품 전략가 등)
- **친절한 메시지**: 오류 발생 시 기술 코드 대신 이해하기 쉬운 안내 제공
- **설계 결과 대시보드**: JSON 대신 시스템 구조, 핵심 흐름, 리스크를 카드로 정리
- **채팅 인터페이스**: 구축 후 AI 전문가에게 직접 질문/지시 가능
- **가상 작업실 시뮬레이터**: 구축 완료 직후 멀티 에이전트 자동 실행 + 중요 사안 사용자 승인 게이트 제공
